# English and Chinese website

The website publishes complete English and Chinese versions, including the fifteen existing articles. English is the default. Language selection is independent of the color theme and does not change project identifiers, article dates, source links or data formats.

## Routes and selection

- `/en/` and `/zh/` are explicit language roots. The same suffix identifies the same page or article in either language.
- The root `/` opens English, or the Chinese homepage when the visitor previously chose Chinese with the language switch. Invalid or unavailable browser storage falls back to English.
- Explicit localized URLs always win over a saved preference. The header switch preserves the route, query string and fragment, and stores the chosen locale when possible.
- Links work without JavaScript. The root has an English no-script redirect. Existing unprefixed pages and Jekyll article URLs point to their Chinese counterparts; bookmarks retain access to the original language.
- `/en/rss.xml` and `/zh/rss.xml` publish localized titles, excerpts, categories and links. `/en/feed.xml` and `/zh/feed.xml` are aliases. Existing `/rss.xml` and `/feed.xml` subscriptions remain Chinese.
- Localized pages carry language tags, canonical URLs, `hreflang` alternates and an English `x-default`. The sitemap lists canonical localized pages and excludes compatibility redirects and error pages.

## Content maintenance

Use descriptive copy about the work: data validation and cleaning, research methods and result records, and the evidence behind investment decisions. Avoid evaluative claims such as “reliable data” or “useful tools” when introducing the author’s work.

UI copy, project titles/descriptions and personal-page text live in `src/i18n/en.ts` and `src/i18n/zh.ts`. Use semantic keys and named interpolation. `src/i18n/index.ts` resolves messages, falls back to English for a missing translation and applies locale-aware plural rules. Dates use `Intl.DateTimeFormat` with the explicit `Asia/Shanghai` time zone.

The project catalog in `src/data/projects.ts` retains stable repository names, group identifiers and URLs, referring to localized copy through message keys. Shared views in `src/views/` render the two languages without duplicating layout or business logic.

Chinese article sources remain in `src/content/blog/`; English translations live in `src/content/blog-en/`. Use the **same filename, date and stable slug** for each pair. Translate the title, categories and complete body, preserving numerical meaning, qualifications, source links and structure. Do not translate a summary and label it a full article. English excerpts stop at word boundaries. Reading-time estimates use words for English and characters for Chinese.

The renderer defensively falls back to a Chinese original with an English notice and an explicit `lang="zh-CN"` body if a translation is absent. Current publication checks require an English counterpart for every existing article, so new article publication should include both languages. UI and article fallback are distinct behaviors.

## Validation

Node.js 22.18 or newer is required, including native TypeScript support for the catalog tests.

Run `script/check` for Astro/TypeScript diagnostics, the production build, legacy redirects, internal links, catalog coverage, interpolation/plural/fallback behavior, translated article pairing and source-link checks.

For browser regression checks:

```sh
pnpm exec playwright install chromium
pnpm run test:browser
```

The browser script starts its own temporary server on a free loopback port. It checks four viewport sizes, both languages and themes, all thirty rendered articles, language preference, route/query/fragment preservation, old links, unavailable storage and no-script navigation. Optional `SCREENSHOT_DIR` saves disposable screenshots outside source control. CI runs these checks after the static build and before deployment.

Implementation baseline: `96b95e0ee4695c9cf1135f0e9d03ea19e4c5e1ae`. The original Chinese Markdown files are unchanged.

Validation on the implementation based on that revision: Astro diagnostics reported zero errors, warnings or hints; 63 pages and 17 legacy redirects built; 80 HTML files and 867 internal links passed. Eight unit/build checks passed, as did the browser matrix and all thirty article pages. A language-switch regression was reproduced for an in-page category change, corrected and verified. A separate translation review checked all article pairs, numerical unit conversions, source URLs, paragraph coverage and uncertainty qualifiers.
